# 接续说明

## 当前工作

本工程是 arXiv:2603.28636v1 的中文教学展开，六章主证明已经写成：

1. **先把问题说清楚**：定义问题、量词和匹配保证数。
2. **怎样保证所有配对互不冲突**：交错路、亏损公式、平方根邻域界。
3. **为什么任何情形都至少能配出这么多对**：一般位置与特殊位置的下界证明，三类单射及端点检查。
4. **怎样构造只能配出少量对的例子**：两参数上界构造、整除与同余条件、区间内倍数计数。
5. **上下界怎样合成精确答案**：单调性、平方数与相邻乘积的边界、取整及精确公式。
6. **把抽象证明落到具体计算上**：完整数值例子与前面论证的对应。

主要结论为每个正整数 m 都满足

\[
f(m)=\min\bigl(m,\lceil2\sqrt m\rceil\bigr).
\]

本讲义展开原论文已有的证明；不把它记为新的定理，也不声称本工程重新完成了 Lean 核验。

## 可继续编辑的入口

- 主源文件：`Erdos650_高中生证明详解.tex`，已合并为一个完整文件。
- 阅读成品：同名 PDF。
- 编译：`bash build.sh`，采用普通完整 TeX Live 或 MiKTeX 中的 XeLaTeX，显式关闭 shell escape，连续编译三遍。
- 文件校验：`python3 verify.py`。
- 有限数值检查：`python3 check_examples.py`。

具体实际检查及其适用范围以 `PROOF_CHECKS.md` 和 `qa/example_checks.json` 为准。数值检查与文件哈希校验分别回答不同问题，均不能代替一般性证明。

## 接续方式

下一步可从用户新增的要求继续，例如补充练习、增加某一处推理的解释、扩展具体例子或调整版式。现有六章的主证明已完成，没有预设的“尚待证明章节”需要自动重写。

编辑时先定位相关章节及其引用。保留定义中的正整数条件、双方互异条件和开区间条件；下界中特殊位置删去的两个顶点、三种类型及取整边界均应同步核对。若改动数值例子，也应同步检查对应计算脚本与结果记录。

形成新版本时，重新编译并检查成品版面，再核对相应数学变更；最后更新检查记录和 SHA256SUMS。新记录只写实际执行的检查，不将未执行的检查记为通过。
